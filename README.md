# ⚛️ Proyek Membangun Application Menggunakan React

Project frontend untuk membangun sebuah aplikasi menggunakan **React** dan JavaScript.

## 📌 Deskripsi

Project ini dibuat untuk mempelajari dan menerapkan konsep dasar pengembangan aplikasi menggunakan **React**.

Dalam project ini, saya mempelajari bagaimana membuat tampilan aplikasi dengan component, mengatur struktur project, serta mengembangkan interface yang interaktif menggunakan React.

## 🚀 Fitur

- ⚛️ Menggunakan React
- 🧩 Menggunakan konsep Component
- 🎨 Membuat tampilan aplikasi
- 🔄 Mengelola data dan tampilan secara dinamis
- 📱 Tampilan yang dapat dikembangkan untuk berbagai ukuran layar
- 💻 Menggunakan JavaScript

## 🛠️ Teknologi yang Digunakan

- React
- JavaScript
- HTML
- CSS
- Node.js
- npm

⚙️ Cara Menjalankan Project
1. Clone Repository
git clone https://github.com/firman-sys/Proyek-Membangun-Application-Menggunakan-React.git
2. Masuk ke Folder Project
cd Proyek-Membangun-Application-Menggunakan-React
3. Install Dependencies
npm install
4. Jalankan Project
npm run dev

Setelah berhasil dijalankan, buka alamat localhost yang muncul pada terminal.
